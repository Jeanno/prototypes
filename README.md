# prototypes

Small standalone experiments.

- [submarine-sonar](submarine-sonar/index.html): touch-friendly interactive submarine sonar simulation (scope, waterfall, active pings, helm, target motion analysis).
- [vocab](vocab/index.html): Wordhoard, an English vocabulary trainer. Level test estimates vocabulary size (CEFR / IELTS-equivalent), suggests the most useful words just past your level, and reviews them with spaced repetition (multiple choice, typed recall). 22k-word list with usage examples built by `vocab/build_words.py` from WordNet, wordfreq and Tatoeba.
