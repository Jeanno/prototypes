# prototypes

Small standalone experiments.

- [submarine-sonar](submarine-sonar/index.html): touch-friendly interactive submarine sonar simulation (scope, waterfall, active pings, helm, target motion analysis).
- [submarine-crew](submarine-crew/index.html): station mockups for a 10-player co-op submarine sim (Captain, Comms, Navigator, Helm, Fire control, Torpedo room / deck gun, Power, Life support, Damage control), all showing the same moment aboard Fathom. Sonar is submarine-sonar.
- [vocab](vocab/index.html): Wordhoard, an English vocabulary trainer. Level test estimates vocabulary size (CEFR / IELTS-equivalent), suggests the most useful words just past your level, and reviews them with spaced repetition (multiple choice, typed recall). 22k-word list with usage examples built by `vocab/build_words.py` from WordNet, wordfreq and Tatoeba.
- [visited-globe](visited-globe/index.html): Wanderglobe, a three.js globe of the places you've been. Click countries to light them up, pin places (search or click, with date and note), set a home for flight arcs; multiple travellers with compare mode, JSON export/import. Data stays in localStorage.
